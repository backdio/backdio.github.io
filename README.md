**BACKD** is a public discovery protocol for early-stage startups.  
It ranks startups based on real community conviction — not hype, ads, or pay-to-win mechanics.

🌐 **Live platform:** [https://backd.io](https://backd.io)

---

### What is BACKD?

BACKD helps founders and scouts discover which early-stage startups are actually gaining real support from the internet.

- Community-driven rankings
- Transparent conviction signals
- Public leaderboards
- Boosts & Launchpad Spotlight (optional visibility tools)
- Built for founders, operators, and independent scouts

---

### Key Features

- **Startup Rankings** — Global leaderboard based on community signal
- **Trending** — Real-time momentum and velocity
- **Explore** — Browse startups by category and stage
- **Power Boosts** — Weighted community support
- **Launchpad Spotlight** — Temporary visibility for new launches
- **Scout Profiles** — Reputation system for reviewers
